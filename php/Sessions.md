# PHP Sessions

Session variables are stored in an associative array called `$_SESSION`. These variables can be accessed during the lifetime of a session.

How it works: PHP generates a random session ID, sends it to the browser in a cookie (`PHPSESSID` by default) and stores the data **on the server** (files by default). On each request the browser sends the cookie back and PHP loads the data.

> See also: [cookies](cookies.md), [forms 2](forms2.md) (flash messages, CSRF token).

## Start a Session

A PHP session is started by calling `session_start()`. This function resumes the current session if the browser sent a valid session ID, or starts a new one. It sends a cookie header, so call it **at the beginning of the page, before any output**.

```php
<?php
session_start();
```

Avoid the "already started" notice when the code may run twice:

```php
if (session_status() === PHP_SESSION_NONE) {
    session_start();
}
```

## Secure session cookie

Configure the session cookie **before** `session_start()` (or in `php.ini`):

```php
<?php
ini_set('session.use_strict_mode', '1');   // reject session IDs not generated by the server
ini_set('session.use_only_cookies', '1');  // never accept the ID from the URL

session_set_cookie_params([
    'lifetime' => 0,          // until the browser is closed
    'path'     => '/',
    'secure'   => true,       // HTTPS only
    'httponly' => true,       // not readable from JavaScript
    'samesite' => 'Lax',      // basic CSRF protection
]);
session_name('MYAPPSESSID'); // optional: custom cookie name
session_start();
```

## Create a Session and a Session variable

```php
<?php
// start a session
session_start();

// initialize session variables
$_SESSION['logged_in_user_id'] = 1;
$_SESSION['logged_in_user_name'] = 'Tutsplus';
$_SESSION['cart'] = ['apple' => 2];  // any serializable value (arrays, scalars...)

// access session variables
echo $_SESSION['logged_in_user_id'];   // 1
echo htmlspecialchars($_SESSION['logged_in_user_name']); // Tutsplus
echo $_SESSION['theme'] ?? 'light';    // default value if not set
```

## Modify Session variable

The following example registers a variable called **count** that is incremented each time the page is visited during the session. `isset()` (or `??`) checks if the session variable is already set.

```php
<?php
session_start();

$_SESSION['count'] = ($_SESSION['count'] ?? 0) + 1;

echo "Visits in this session: {$_SESSION['count']}";
// 1st load: Visits in this session: 1
// 2nd load: Visits in this session: 2
```

## Login / logout example

Regenerate the session ID when the privilege level changes (login, logout, role change) to prevent **session fixation**:

```php
<?php
// login.php
declare(strict_types=1);
session_start();

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    // $pdo: see PDO/Conexion.md
    $stmt = $pdo->prepare('SELECT id, name, password_hash FROM users WHERE email = ?');
    $stmt->execute([$_POST['email'] ?? '']);
    $user = $stmt->fetch();

    if ($user && password_verify($_POST['password'] ?? '', $user['password_hash'])) {
        session_regenerate_id(true);           // new ID, delete the old session
        $_SESSION['user_id']   = $user['id'];
        $_SESSION['user_name'] = $user['name'];
        $_SESSION['last_seen'] = time();
        header('Location: dashboard.php', true, 303);
        exit;
    }

    $error = 'Invalid email or password'; // don't reveal which one is wrong
}
```

Protect a page:

```php
<?php
// dashboard.php
session_start();

if (!isset($_SESSION['user_id'])) {
    header('Location: login.php');
    exit;
}

// Inactivity timeout: 30 minutes
if (time() - ($_SESSION['last_seen'] ?? 0) > 1800) {
    $_SESSION = [];
    session_destroy();
    header('Location: login.php?expired=1');
    exit;
}
$_SESSION['last_seen'] = time();

echo 'Welcome ' . htmlspecialchars($_SESSION['user_name']);
```

## Destroy a Session variable

If you want to destroy a single session variable then you can use the `unset()` function.

```php
<?php
unset($_SESSION['count']);
```

## End a Session

`session_destroy()` deletes the data on the server, but it doesn't clear `$_SESSION` in the current request nor delete the browser cookie. A complete logout:

```php
<?php
// logout.php
session_start();

$_SESSION = [];                               // 1. clear the variables

if (ini_get('session.use_cookies')) {         // 2. delete the cookie
    $p = session_get_cookie_params();
    setcookie(session_name(), '', [
        'expires'  => time() - 42000,
        'path'     => $p['path'],
        'domain'   => $p['domain'],
        'secure'   => $p['secure'],
        'httponly' => $p['httponly'],
        'samesite' => $p['samesite'],
    ]);
}

session_destroy();                            // 3. delete the server data

header('Location: login.php');
exit;
```

## Useful functions

```php
session_id();               // current session ID
session_regenerate_id(true); // new ID (true = delete old data file)
session_status();           // PHP_SESSION_DISABLED | PHP_SESSION_NONE | PHP_SESSION_ACTIVE
session_write_close();      // save and release the session lock early (long requests, parallel AJAX)
```

> ⚠️ The session is locked while a request uses it: concurrent requests from the same user wait. Call `session_write_close()` once you no longer need to write to it.
